mulation

Coverage can lie. Mutation doesn’t.

A green suite can hit every line and still miss a boundary bug. mulation changes the code and asks whether a test fails.

See the gap Download release

What CI usually trusts

  • PASS unit tests green
  • 100% line coverage on is_adult
  • SHIP looks safe

What mulation finds

age >= 18   →   age > 18
TEST(Adult, TwentyIsAdult)   still PASS
mutant survived — no age-18 assertion

Covered ≠ tested.

A real hole under “good” coverage

Product code returns age >= 18. The unit test only checks age 20. Coverage marks the line executed. Change the operator to > and the suite stays green — age 18 is never asserted. 

mulation -- ./compare_tests

  [survived]  compare.cpp:4  [ROR] >= -> >
  [survived]  compare.cpp:8  [ROR] >  -> >=
  [killed]    compare.cpp:12 [AOR] +  -> -

score: 33%   ← coverage said 100%; mutation said the suite is weak

Same habit as Valgrind

Keep writing Google Test. Keep running CTest. Add mulation as the gate that asks: if this operator were wrong, would a test fail? 

mulation --git-diff --min-score 80 -- ./build/my_tests
mulation --git-diff --min-score 80 -- ctest --test-dir build

Install, instrument, gate

Linux x86_64 release + Clang/LLVM 18. One command installs to $HOME/.local; instrument the SUT once, flip mutants at runtime. 

curl -fsSL https://raw.githubusercontent.com/YanChao1999/mulation-bot/v0.0.1/scripts/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"

CXX="mulation c++" CC="mulation cc" cmake -B build && cmake --build build
ctest --test-dir build          # must stay green
mulation --git-diff --min-score 80 -- ./build/my_tests

Prefer a tarball? Grab Releases or pin MULATION_VERSION=v0.0.1 when running the script.

What the score means

killed
A test failed or timed out — the suite noticed the injected bug.
survived
Suite still green after the fault — coverage may have hit the line, but no assertion depended on the correct operator.
score
killed / (killed + survived). Use --git-diff so PR campaigns stay cheap.

Honest limits

Clang/LLVM 18 on Linux today. Needs a rebuild with the pass plugin — not pure DBI. Equivalent mutants can inflate “survived.” Young tool; niche is a thin gtest/CTest gate that proves weak tests before production.
